# MEDISYS - Sistema Integral

Repositorio del proyecto de titulación MEDISYS.

## Arquitectura del Proyecto

El sistema está dividido en dos módulos principales:

- **`medisys-frontend/`**: Interfaz de usuario SPA construida con Vue.js y Vite.
- **`medisys-backend/`**: Servidor de backend y API REST desarrollado con Node.js y Express.

## Ejecución Local

### Backend
```bash
cd medisys-backend
npm install
npm start
